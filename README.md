## Project Overview

This project investigates whether an NBA team's performance over its previous five games can predict whether it will win its next game.

We analyze game records from the 2025–26 NBA regular season for five teams:

- Boston Celtics (BOS)
- Toronto Raptors (TOR)
- Los Angeles Lakers (LAL)
- San Antonio Spurs (SAS)
- Oklahoma City Thunder (OKC)

Our primary approach uses logistic regression to predict wins and losses based on recent team performance. We also incorporate ARIMA (Autoregressive Integrated Moving Average) forecasting to investigate whether explicit time-series modeling improves prediction accuracy.

### Research Question

Can an NBA team's performance over its previous five games help predict whether it will win its next game?

### Project Goal

Build a predictive model that achieves at least **65% accuracy on chronologically held-out games** and outperforms a baseline that predicts the home team will win.

We will compare:

1. A home-team baseline.
2. Logistic regression using previous-five-game statistics.
3. Logistic regression incorporating ARIMA forecasts.

## 3. Dataset Description

The dataset contains game-level observations from the 2025–26 NBA regular season.

According to our MI2 dataset establishment:

- **Original observations:** 410 team-game records
- **Teams:** 5
- **Games per team:** 82
- **Excluded observations:** First 5 games per team
- **Eligible observations:** 385

These counts will be verified when the analysis notebook processes the original CSV files.

### Predictor Variables

For each team, the following statistics will be calculated using its previous five games:

| Feature | Description |
|---|---|
| avg_points_last5 | Average points scored over the previous five games |
| avg_point_diff_last5 | Average point differential over the previous five games |
| avg_rebounds_last5 | Average rebounds over the previous five games |
| avg_turnovers_last5 | Average turnovers over the previous five games |
| home_away | Whether the team is playing at home or away |

The target variable is `win_loss`, where:

- `1` = Win
- `0` = Loss

All rolling features will exclude the current game to prevent data leakage.

## 4. Instructions for Reproducing Results

### Step 1: Access the Repository

Download or clone this GitHub repository.

Ensure that the original five CSV files are available in the `DATA/` directory.

### Step 2: Open the Analysis Notebook

Open `SCRIPTS/Project2_NBA_Analysis.ipynb` in Google Colab.

The notebook will contain the complete workflow in execution order.

### Step 3: Load the Dataset

Run the data-loading section to import the five team CSV files and combine them into a single dataset.

### Step 4: Preprocess the Data

The preprocessing workflow will:

1. Organize games chronologically by team.
2. Check for missing or invalid observations.
3. Verify missing statistics against the original data.
4. Exclude records with unrecoverable missing values.
5. Calculate rolling averages using each team's previous five games.
6. Exclude each team's first five games.

### Step 5: Split the Dataset

The analysis will use a chronological training and testing split.

| Dataset | Dates | Observations |
|---|---|---|
| Training | Oct. 30, 2025 – Mar. 14, 2026 | 309 |
| Testing | Mar. 15, 2026 – Apr. 12, 2026 | 76 |

This corresponds to approximately:

- **80.26% training**
- **19.74% testing**

The dates and observation counts are those specified in our latest MI2 methodology and will be verified against the source files.

Records from the same matchup will remain in the same partition to reduce the risk of data leakage.

### Step 6: Train Logistic Regression

Train a logistic regression classifier using the previous-five-game rolling statistics and home-court indicator.

The model will predict whether each team wins or loses its next game.

### Step 7: Perform ARIMA Forecasting

Use ARIMA to forecast each team's next-game points scored based on its historical scoring performance.

ARIMA forecasts will be generated using only information available before the game being predicted.

The forecasts will then be incorporated as additional predictors in a second logistic regression model.

This allows us to compare the original classification approach with an approach that incorporates explicit time-series forecasting.

### Step 8: Evaluate Model Performance

Evaluate predictions on the held-out test set using classification accuracy.

Compare:

1. Home-team baseline.
2. Original logistic regression.
3. Logistic regression with ARIMA forecasts.

The primary success criteria are:

- Achieve at least 65% test accuracy.
- Outperform the home-team baseline.

We will also examine whether ARIMA improves prediction accuracy compared with logistic regression alone.

### Step 9: Save Outputs

Save generated datasets, figures, tables, and evaluation results in the appropriate repository directories.

## 5. Exploratory Data Analysis

Our MI2 exploratory analysis examined:

1. The distribution of points scored across the five selected teams.
2. The relationship between previous-five-game point differential and next-game results.

The initial dataset analysis reported:

- Average points scored: approximately **116.94 points per game**.
- Average previous-five-game point differential before losses: **+6.31**.
- Average previous-five-game point differential before wins: **+6.39**.

These preliminary findings suggest that recent point differential alone may not strongly distinguish wins from losses.

## 6. Limitations

This project has several limitations:

- The dataset includes only five selected teams and one NBA season.
- Team performance may be influenced by injuries, rest, opponent strength, and roster changes that are not directly modeled.
- Some matchups between selected teams appear twice, once from each team's perspective.
- A relatively small test set may make minor accuracy differences difficult to interpret.
- ARIMA forecasting may be limited by the relatively short scoring history available for each team.
- Results may not generalize to other teams or seasons.

The analysis is intended for academic research rather than sports betting or financial decision-making.
